# Agent Note: W4 和 W5 实验保持明确且有界的授权

Status: implemented

## Problem

实验请求格式可能在缺乏持续提速或质量证据时，扩大供应商调用、缓存复用或结果接受范围。本笔记保留原 ADR-0003 的实验部分，于 2026-09-17 整理，记录既有边界，不代表开始新一轮实验上线。

## Decision

W4 单正文和 W5 历史整体标记候选方案默认关闭，需要明确、有界的内存授权。仅编译的影子结果不能授权供应商调用。

W4 最多允许两次应用层派发、三次实际网络请求，包含共享兼容重试。启用缓存的 W4 授权使用独立 D 缓存身份。W5 只接收完整且合格的原始批次，不持久化自己的结果。当前准入和显示行为归属[功能与行为说明](../../../../docs/product.md)。

## Alternatives considered

未接受把影子运行或离线结构检查通过，当成调用供应商或默认启用的许可。W4 未证明持续提速，因此不足以自动转为默认。早期记录未列出其他实验替代方案。

## Consequences

结构测试、语义评估、供应商耗时和真实客户端显示分别验证。默认关闭的路径仍有明确的生产边界；仅凭名称或没有静态调用者，不能证明安全可删。[校验约束](2026-09-17-validation-and-repair-boundaries.md)独立于请求格式实验存在。
