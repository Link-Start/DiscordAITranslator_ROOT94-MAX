# Agent Note: 区分翻译显示、就绪状态和宿主生命周期

Status: implemented

## Problem

重新挂载整个聊天区会干扰输入框和阅读位置。供应商返回响应或结果已经存储，都不足以证明消息已可阅读。本笔记保留原 ADR-0003 的显示部分，于 2026-09-17 整理；该日期不表示所有运行时变化都在当天交付。

## Decision

保留不可变原文及唯一显示负责人。按完整消息提交结果，通过 Store 定向修订重绘已挂载的消息/回复界面，并进行有界重试。状态更新不得重绘消息列表。尊重用户最新滚动意图；插件生命周期及全局设置重新初始化与翻译结果重绘分开处理。

累计就绪状态按频道及唯一消息身份计数，耗时属于单个工作轮次。显示恢复使用已存译文，不新增翻译请求。当前机制与边界情况归属[功能与行为说明](../../../../docs/product.md)，不在这里维护第二份清单。

## Alternatives considered

同步清空再重新挂载的重绘方式会干扰阅读和输入框，因此已否决。修改 Discord Store 原始记录会破坏不可变原文边界。没有 updater 的合成组件不能作为可靠的重绘入口。为了凑满配置上限而任意翻页读取历史也已否决；初始预取继续保持有界。

## Consequences

渲染、存储结果和状态计数各自需要证据。自动结构检查不能证明真实客户端渲染正确；不能把生命周期刷新误当成翻译结果重绘。可复用的调查方法和待观察事项由下方各文档分别维护。
