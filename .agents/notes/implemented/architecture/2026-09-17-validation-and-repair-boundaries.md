# Agent Note: 只修复可归因的失败，区分结构正确与含义正确

Status: implemented

## Problem

类似名称的文本与格式损坏的批次响应需要不同恢复规则。报告的失败数减少，不足以证明翻译质量提高。本笔记保留原 ADR-0003 的校验部分，于 2026-09-17 整理，不宣称每项运行时决策都最初发生在该日期。

## Decision

只修复能归因到响应消息/范围身份的失败。不能根据位置猜测未知 ID，也不能接受损坏的保护标记。响应结构完整不能证明语义准确。

保留按身份归因、保护标记检查和有界修复。原 P3 在修复耗尽后自动保留失败片段及其显示规则，已由[批内语境与整条结果](../bug-fix/2026-09-17-batch-context-whole-result.md)替代；不能把该旧规则作为当前默认。当前行为由[功能说明](../../../../docs/product.md)和[翻译服务接口约定](../../../../docs/providers.md)维护。

## Alternatives considered

已归档的 3b 收紧方案及 v4 缓存迁移不是获批默认行为。按位置对齐未知响应 ID 会掩盖归因错误；接受损坏保护标记会破坏原文保留。不能仅因离线失败数改善就放宽这些边界。

## Consequences

保留名称的策略仍可能误接受普通语句。结构回归检查与语义评估分别进行，语义质量仍是明确限制。原始事故采集留在私人归档，公开回归使用合成证据。
