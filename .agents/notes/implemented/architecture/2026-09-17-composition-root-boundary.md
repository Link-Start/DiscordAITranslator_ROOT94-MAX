# Agent Note: 模块组装入口保持明确且紧凑的职责

Status: implemented

## Problem

宿主依赖和生命周期接线曾耦合在插件门面中。如果没有新职责归属或具体行为缺陷，却无限要求减少门面行数，会重新开启已经完成的提取工作。本笔记于 2026-09-17 整理既有架构、更新记录和回归证据，不表示当天新增了运行时变化。

## Decision

Slice 5d 模块组装入口（composition root）提取已完成。旧运行时保留插件门面和生命周期补丁外壳；宿主依赖的分发进入对应 wiring 接线模块。19 个延迟单例使用明确清单，每个最多八行，由引用的契约测试约束。

后续每次提取只调整一个已识别的职责边界，保持单文件生成产物及频道/全局职责。移除运行时职责后应同步降低既有行数上限；不得为了新增门面代码提高上限，也不能建立第二套状态映射、重绘负责人、队列、计数口径或原文显示模式。

## Alternatives considered

没有明确职责归属而继续缩减门面，会把已完成提取变成无限的行数任务。在兼容补丁中夹带重新设计，会混淆回归原因。既有文档记录了这些约束，没有记录其他依赖注入设计的对比。

## Consequences

当前模块职责维护在架构说明中，测试维持紧凑单例边界。提取完成不代表独立的渲染、供应商请求中止、生命周期或大模块观察项已经关闭。运行时变化需要针对性回归、可构建且可回滚的修改；跨越 Discord 边界时还需相关客户端证据，合成测试不能单独证明实际显示正确。
