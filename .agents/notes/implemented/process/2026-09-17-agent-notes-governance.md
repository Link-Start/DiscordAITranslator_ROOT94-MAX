# Agent Note: 维护唯一且轻量的设计与经验笔记库

Status: implemented

## Problem

会话历史、当前事实和设计理由曾容易混在一起。公开文档既要保留独有约束，也要防止私人采集、旧计划和本机部署记录进入 GitHub。

## Decision

在 `.agents/notes/` 维护唯一决策库，采用 DSH 的生命周期目录、主题分类和核心格式，具体见[笔记指南](../../README.md)。该库最初在 `docs/adr/` 中适配；迁移名称是为了匹配更广的职责。根 README 继续是面向 GitHub 读者的完整产品文档，分范围的代理指引将维护者带到内容所属主题。

三篇旧 ADR 的证据继续保留：ADR-0001 的临时构建推迟决策被替代后转入冻结历史；ADR-0002 继续作为有效包装决策；ADR-0003 拆分为显示/就绪、校验/修复和实验授权，没有丢弃约束。2026-07-12、2026-07-13 文件名沿用原始首次记录日期，2026-09-17 文件保留后续整理日期。

Node.js 检查笔记目录、有效格式和链接、归档元数据及冻结清单。CI 对照变更前 Git 基线检查归档，必要时包含历史根目录。迁移保留封存字节和清单哈希。所有笔记继续接受隐私检查，历史归档的出站链接允许随时间失效。格式检查不能证明语义正确。

当前事实放在所属主题文档，操作步骤放在调试手册，具体事故证据放在复盘，未关闭观察项集中到一份待验证清单。已完成阶段记录有对应决策负责人，不留在架构说明或当前状态快照里。贡献者沿用贡献指南中的小型迭代循环；笔记不要求强制翻译副本或额外配套系统。

可选 Discord MCP 接入也遵循同一归属：一份手册维护工具发现、重连和诊断步骤；代理和贡献者入口只在需要客户端证据时链接过去。本机配置、辅助脚本和采集留在公开仓库外。工具可用、实际连通、观察到插件行为是三个不同结论；客户端不可用时，保留未完成验证，不能用本地测试通过替代客户端验收。

常用维护文档、有效笔记和入口默认中文，固定命令、路径及结构字段保持稳定。已有英文 README、架构说明和调试指南继续保留，安全反馈在同一文件提供中英说明。中文化不改写冻结归档，也不为每份文档新增翻译副本。

## Alternatives considered

同时保留旧 ADR 树和新笔记树会重复职责；继续只用 ADR 名称，会缩窄包含流程、测试及简化笔记的实际范围。复制完整外部笔记项目会引入无关笔记、资源和运行工具。固定删除比例可能丢掉独有理由。允许修改归档后重新生成哈希，无法保护历史证据。

## Consequences

重要变化更新相关有效笔记，保留被替代的理由；临时证据留在 Git 外。普通编辑可说明为何不需要决策笔记。此整理不增加运行时依赖，也不改变插件行为、部署或合并授权。代码简化需要独立、具备证据的提案。
