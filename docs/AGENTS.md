# 文档维护规则

- 从[文档入口](README.md)出发，只阅读与当前问题有关的主题。
- 根 README 面向 GitHub 读者，完整说明安装、首次使用、功能、限制与支持；保持中英文一致。
- 常用维护文档、有效笔记的标题和正文默认中文，入口链接使用中文名称。已有英文 README、架构说明和调试指南保留；命令、配置键、稳定路径和笔记固定字段不翻译，不为每份文档另建翻译副本。
- 当前行为归属功能、设置和供应商说明；模块职责归属架构说明；操作步骤归属调试手册；具体事故证据归属复盘；未关闭观察项归属待验证清单。通过链接引用所属文档，不复制整段内容。
- 长期决策归属[设计与经验笔记](../.agents/notes/README.md)，`.agents/notes/` 是唯一笔记库。长期执行规则放在对应范围的 AGENTS 文件中。
- 在原位置更新当前事实。私人对话、每轮运行结果、原始采集、账号和本机路径留在 Git 外；笔记引用合成回归或公开来源，不引用原始私人采集文件。
- 文档超过篇幅预算时，按读者的问题拆分；不能为了缩短篇幅删除独有约束。整理时保留理由和被否决的路线。
- 文档修改后运行 `npm run check:publication` 和 `npm run check:notes`；完整交付检查为 `npm run verify`。
