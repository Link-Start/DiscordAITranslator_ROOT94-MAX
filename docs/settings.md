# 设置说明与配置迁移

<a id="principle"></a>

## 职责划分

频道设置回答“当前频道怎样翻译”；全局设置回答“所有频道采用什么默认值、凭证、保护规则和显示策略”。

同一行为只有一个权威编辑入口，不在两处重复放置同一个开关。

<a id="channel-popout"></a>

## 频道弹窗

| 设置 | 作用范围 | 保存方式 |
| --- | --- | --- |
| 主翻译供应商 | 当前频道 | 保存明确频道覆盖值；恢复后跟随全局 |
| 收到消息输入语言 | 由既有范围锁选择频道、服务器或全局 | 使用既有分范围语言存储 |
| 收到消息输出语言 | 由既有范围锁选择频道、服务器或全局 | 使用既有分范围语言存储 |
| 发送消息输入语言 | 由既有范围锁选择频道、服务器或全局 | 使用既有分范围语言存储 |
| 发送消息输出语言 | 由既有范围锁选择频道、服务器或全局 | 使用既有分范围语言存储 |
| 语言识别助手 | 本次交互 | 只有用户应用结果时才保存 |

频道弹窗不放自动翻译开关、备用供应商、凭证、全局显示设置或只读状态行。

<a id="channel-toggle"></a>

## 频道翻译开关

- 右键点击翻译图标，只切换当前频道的翻译总开关。
- 没有明确记录的频道默认关闭。
- 开关控制自动收发翻译及当前讨论串/论坛标题；无论频道是否开启，都可手动翻译消息。
- 关闭频道时清理待处理自动工作，恢复当前显示的收到消息译文、回复预览、嵌入内容和讨论串标题，包括之前的手动译文。
- 保留有效翻译缓存和发送消息原文/编辑元数据。关闭后再次执行手动操作，可显示该单条消息的缓存或新译文。
- 不提供全局默认自动翻译开关。

<a id="global-betterdiscord-settings"></a>

## BetterDiscord 全局设置

全局设置分为五个可用键盘访问的标签页，左右方向键、Home 和 End 用于切换。

弹窗标题跟随插件的有效界面语言，选择“跟随 Discord”时也会翻译标题。主服务与备用操作使用等宽、等高的按钮。

| 标签页 | 设置内容 |
| --- | --- |
| 翻译服务（Providers） | 分组供应商导航、全局主备角色、凭证、端点、持久化模型目录和连接测试 |
| 翻译（Translation） | 句式化收发方向、可搜索语言控件、原文过滤、AI/基础决策模式、提示词库、语言识别和历史补翻 |
| 通用（General） | 界面语言、关联的原文呈现、回复预览行为、译文颜色和实时预览 |
| 高级（Advanced） | 并发与流式显示、缓存容量与清理、保护词、包裹符对、收发作用范围和翻译前缀 |
| 诊断（Diagnostics） | 版本/构建身份、服务状态、翻译表现、折叠排障详情、可复制诊断和只读发布检查 |

即使供应商只被某个频道覆盖值选中，其凭证设置也必须可访问。已作为主备的供应商字段，不在附加供应商区域重复出现。

获取到的模型标识保存在每个供应商有上限的目录中。只有保存的端点指纹与当前端点匹配时才显示该目录。凭证文本使用防抖写入，并在失去焦点、供应商/标签页变化、关闭设置和停止插件时强制提交。

译文水印始终显示，不是设置项。

### 翻译缓存

容量、保存、淘汰规则及清除操作的影响统一收在卡片标题旁的“？”提示中。已用数量和容量输入保持直接可见；清除按钮仅显示居中的文字，不附加图标。

高级页的独立缓存卡片显示当前条数和容量。全局键 `general.translationCacheLimit` 默认 500，接受 100～10,000 的整数，输入框失焦或按 Enter 后保存。旧配置缺少该值或值非法时，运行时采用 500；界面拒绝非法输入并保留已有设置。

正常译文和需要服务判断的跳过记录共用容量。缩容按 `cachedAt` 淘汰最旧记录并保存，扩容不会清除或恢复已有记录；重启加载和后续写入也遵守该上限。容量变化不触发翻译请求。实验性 whole-marker 分区仍独立保持 500 条上限，不由此设置控制。

“清除翻译缓存”停止当前补翻、恢复原文并清除翻译结果和跳过记录；后续重新翻译可能再次产生服务费用。日常入口不再提供重置本轮并发或清除速度学习记录，底层排障接口保留。

### 诊断信息层级

顶部保留版本号，具体构建号放在默认折叠的“排障详情”中并保留在复制报告里。运行状态展示 BDFDB 和主备服务；“翻译表现”只显示最近翻译、队列等待、主备切换、超时/限流。最近接口测试、耗时分位数、流式及批量计数、客户端显示状态也放在“排障详情”中，直接排列指标，不再加一层分类标题。

“实时完整响应 / P50 / P95”旁的“？”说明分位数，“输入 / 输出长度”旁的“？”说明计数单位。P50 是中位耗时，P95 表示 95% 样本不超过该耗时，至少五个样本才显示。样本不足不代表故障。首段响应达标判断和流式资源计数不再占用界面，复制的脱敏报告继续保留这些工程证据及单位定义。

<a id="permanent-controls"></a>

## 固定提供的入口

以下是固定产品入口，不是可选设置：

- 输入框翻译按钮
- 消息操作栏翻译按钮

旧存储中试图隐藏这些按钮的值会被忽略。

<a id="removed-controls"></a>

## 已移除的设置

- 输入框翻译按钮可见性
- 消息操作栏翻译按钮可见性
- 全局默认自动翻译开关
- 重复的全局语言识别助手
- 频道弹窗中重复的发送原文、收到原文控制
- 直接显示收到消息原文的模式（`showOriginalDirectly`）；唯一的收到原文开关继续使用既有行内引用/剧透呈现

<a id="migration-rule"></a>

## 旧配置迁移规则

1. 保留每个频道明确的 true 或 false 记录。
2. 将继承的自动翻译默认值设为 false。
3. 不把继承开启的频道转换为明确开启记录。
4. 右键修改始终限定到当前频道。
5. 关闭后清理受影响频道的待处理自动工作，恢复其全部已显示的收到消息译文。
6. 从两个输出语言选择器中移除 `$discord`。首次加载时，将全局、服务器或频道范围中旧的收发输出别名替换为客户端当前具体语言，并保存明确选择。
7. 旧自定义 `aiAutoTranslatePrompt` 只迁移一次，成为提示词库首个自定义条目；旧内置提示词解析为当前只读内置模板。

已退役的 `$discord` 只作为迁移/兼容输入可读。重载时通过 `BDFDB.LanguageUtils.getLanguage().id` 解析；下游规范化器也会在签名、同语言、文字系统、派发和结果校验比较前解析旧内存值。供应商原样回显且识别源语言等于具体目标语言时，按同语言终态跳过。失败历史快照保留已解析的配置签名：普通扫描继续停放匹配的失败，明确重试可绕过该保护。

`showOriginalMessage` 是唯一的收到原文设置。忽略存储中的 `showOriginalDirectly`，不恢复第二种呈现模式。
